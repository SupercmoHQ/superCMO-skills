# Prompt guide — grok-video (xAI)

Quick text/image-to-video drafts. Reach for it when the user wants to sketch an idea fast and iterate.

Frame the prompt: Subject → Action → Environment → Camera → Mood.

- Write in natural language — a short scene description, not a keyword tag list.
- Lead with the motion; in a draft, the movement matters more than fine detail.
- Use director language for the camera — "slow pan", "tracking shot", "static wide".
- Tone: replace generic words ("nice", "cool") with atmosphere ("nostalgic", "tense", "playful").
- Keep it short — drafts iterate fast; refine the prompt across takes rather than overloading one.
