# Prompt guide — gpt-image-2

Order every prompt alike, line breaks between parts: **Scene** — setting; **Subject** — focus; **Important details** — visible specifics; **Use case** — the artifact being made; **Constraints** — boundaries. Split intricate briefs into labeled segments. Name the deliverable literally; the use case sets mode and polish.

## Strengths

- Spells accurately in Latin and CJK; holds composition and material logic.
- Wrap literal text in quotes or ALL CAPS; give font, size, colour, placement; spell hard words letter by letter; demand it verbatim. 

## Multiple inputs

- Label each input by index and role, then say which elements move where — for example "Image 1: the
  product, Image 2: the marble backdrop", then "place the product from Image 1 onto the backdrop in
  Image 2".
- Repeat the preserve list every iteration; restate identity anchors verbatim.

## Rendered look

- Name light sources, colour temperature, and surface materials; give camera as a feel.
- Say photorealistic explicitly when that is the mode.
- For a product or a UI, describe it as a finished, shipping thing — not a concept sketch or mockup.
- No transparent backgrounds.

## Revising

- One change per turn, written as Change / Preserve / Constraints.
