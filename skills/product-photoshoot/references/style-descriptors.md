# Helper — style anchors

Vague descriptors ("clean", "soft light") produce generic results. Anchor the style to something the
model already knows densely — but use **concepts, not living people**: living-artist and brand names
trip content filters and carry IP risk, and concrete craft anchors give more control anyway.

Pull 2–3 anchors from across these categories, then add palette, surface, and mood; match them to the
brand and mode:

- **Movement / era** — e.g. Bauhaus, Art Deco, Memphis, mid-century modern, brutalist, wabi-sabi,
  Flemish still-life, vaporwave.
- **Film stock** — e.g. Portra 400, Ektachrome, Cinestill 800T, Tri-X black-and-white.
- **Camera & lighting** — e.g. medium-format large-negative clarity, beauty-dish key light, ring-light
  catchlight, hard direct flash, softbox-and-fill.
- **Genre register** — e.g. high-fashion beauty editorial, minimalist e-commerce catalog,
  food-magazine overhead, architectural interior.

Example: *"Memphis color-blocking, shot on Portra 400, hard direct flash, glossy seamless backdrop."*
